# Translations

Twake Mail uses [twake-i18n](https://github.com/cozy/cozy-libs/tree/master/packages/twake-i18n)
(Polyglot). The dictionaries are `common/src/locales/{en,fr,ru,vi}.json`.

## Rules

- No hard-coded user-facing string: every string goes through `t()` from
  `@common/i18n/useI18n`, which types the keys against `en.json`.
- Every key exists in the four languages (`locales.spec.ts` checks it).
- Nested JSON, grouped by screen or feature: `login.submit`, `topbar.logout`.
- Placeholders: `%{name}`, e.g. `t('mailbox.moved', { name })`.
- Plurals: forms separated by ` |||| `, picked with `smart_count`, e.g.
  `"%{smart_count} message |||| %{smart_count} messages"` and
  `t('key', { smart_count: 3 })`. English and French have 2 forms, Russian 3
  (one, few, many), Vietnamese 1.
- When tmail-flutter already has the string, reuse its translations
  (`lib/l10n/intl_*.arb`, template `intl_messages.arb`) with the script below.

## Importing strings from tmail-flutter

```bash
npm run import-flutter-arb -- \
  --arb-dir ../tmail-flutter/lib/l10n \
  new_message=sidebar.newMessage \
  sign_out=topbar.logout
```

- Each argument is `<arbKey>[=<target.path>]`; the target defaults to the ARB
  key. The value is written in every locale file (`--locales en,fr` to
  restrict, `--dry-run` to preview).
- English comes from `intl_messages.arb`, the template. A key missing from a
  locale ARB falls back to English, with a warning: translate it by hand.
- ICU placeholders `{x}` become `%{x}`; ICU quotes (`''`, `'{'`) are
  unescaped.
- A plural `{count, plural, =1{…} other{…}}` becomes the Polyglot forms of
  the locale; its variable is read from `smart_count`, also in locales whose
  ARB translation is not pluralized. Explicit `=0` (or `=2`…) forms have no
  Polyglot equivalent and are dropped with a warning. `select` and nested
  plurals are refused.
- The script reports each conversion; review the diff of the locale files.

The conversion lives in `scripts/lib/icuToPolyglot.mjs`, tested by
`npm run test:scripts`.
