# 0.1.0

First release. The runtime configuration lives in `.env.js` and `appList.js`,
mounted next to `index.html` (`/usr/share/nginx/html` in the Docker image).
See `public/.env.example.js` and `public/appList.example.js`.

## Runtime configuration variables (in `.env.js`)

| Variable | Required | Default | Description |
|---|---|---|---|
| `JMAP_SESSION_URL` | yes | | URL of the JMAP session resource |
| `AUTH_MODE` | no | `oidc` | `oidc` or `basic` |
| `SSO_BASE_URL` | with `oidc` | | OIDC issuer URL |
| `SSO_CLIENT_ID` | with `oidc` | | OIDC public client id |
| `SSO_SCOPE` | no | `openid profile email offline_access` | Keep `offline_access` to get a refresh token |
| `SSO_REDIRECT_URI` | no | `<origin>/callback` | Must be registered on the SSO |
| `SSO_POST_LOGOUT_REDIRECT` | no | `<origin>/` | Must be registered on the SSO |
| `SENTRY_DSN` | no | | Error reporting, disabled when empty |
| `DEBUG` | no | `false` | TanStack Query devtools, nginx cache disabled |
| `LANG` | no | | Default UI language: `en`, `fr`, `ru`, `vi` |
| `CALENDAR_SPA_URL`, `CHAT_SPA_URL` | no | | URI templates of the other Twake apps |
| `WORKPLACE_FQDN_FALLBACK` | no | | Used by the URI templates when the SSO has no workplace FQDN |

## SSO client

Register a public client (no secret) using Authorization Code with PKCE
(S256), with `SSO_REDIRECT_URI` as redirect URI and
`SSO_POST_LOGOUT_REDIRECT` as post-logout redirect URI. Allow refresh tokens.
